# achyutkarthikeyan.xyz

Achyut Karthikeyan's robotics portfolio.

## How the site updates
This repository is published with GitHub Pages. Every change pushed to the
`main` branch goes live at https://achyutkarthikeyan.xyz automatically,
usually within a minute or two. The `CNAME` file tells GitHub Pages the domain.

## Files
- `content.js` — all the text: sections, school stages, projects, awards,
  Ball Boy. Edit this to update the site (instructions are at the top).
- `photos/` — robot photos and CAD screenshots, referenced from content.js.
- `index.html` — the page layout and design. Rarely needs changing.
